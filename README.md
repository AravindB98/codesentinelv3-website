# CodeSentinel website

The public website for CodeSentinel: AI code security review that can prove where every finding came from.

**Live site:** https://aravindb98.github.io/codesentinelv3-website/

Built for INFO 7375 Computational Scepticism, Northeastern University, Fall 2026.

## What is here

| File | Contents |
|---|---|
| `index.html` | The whole site in one file: overview, two live demos, install and run, evidence, user manual, technical manual, pitch deck and market analysis |
| `CodeSentinel_v3_Pitch_Deck.pdf` | The 13-slide pitch deck |
| `pitch-deck.html` | The same deck as a web page |

The live demos run entirely in the browser. The first runs CodeSentinel's 32 offline rules on editable code; the second recomputes a provenance chain and shows a forged finding failing. Nothing is uploaded.

## Source

The site is generated by `site/build.py` in the product repository, [AravindB98/CodeSentinel-v3](https://github.com/AravindB98/CodeSentinel-v3), from that repository's manuals and rule set. Edit there and rebuild; do not edit `index.html` by hand.

## Status

CodeSentinel is a research preview. No accuracy claim is made for production code; the site's Evidence section states what has and has not been measured.
